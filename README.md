# 🚀 Neon Defender: Space Invasion

Game arcade tembak-menembak luar angkasa bergaya retro-neon yang seru, responsif, dan siap dimainkan langsung di browser web kamu tanpa perlu instalasi aplikasi tambahan!

---

## 🎮 Cara Menjalankan Game

1. Buka folder ini di file explorer komputer kamu: `c:\Users\ACER\Downloads\game sederhana`
2. Klik dua kali (**Double-click**) file **`index.html`** untuk membukanya di browser favoritmu (Google Chrome, Microsoft Edge, Firefox, atau Opera).
3. Klik tombol **"MULAI MISI"** dan selamat bermain!

---

## 🕹️ Kontrol Permainan

| Tindakan | Keyboard | Mouse | Layar Sentuh (HP/Tablet) |
| :--- | :--- | :--- | :--- |
| **Gerak Pesawat** | `W, A, S, D` atau `Tombol Panah` | Geser kursor mouse | Sentuh & geser jari |
| **Tembak Laser** | `Spasi` | Klik Kiri (tahan untuk tembak terus) | Otomatis menembak saat menyentuh layar |
| **Ledakan Bom EMP** | Tombol `B` atau `X` | Klik Kanan | Tombol `💣 BOM` di layar |
| **Jeda (Pause)** | Tombol `P` atau `ESC` | Tombol `⏸️` di pojok kanan atas | Tombol `⏸️` di layar |
| **Suara (Mute/Unmute)** | - | Tombol `🔊` di pojok kanan atas | Tombol `🔊` di layar |

## ⭐ Fitur-Fitur Menarik

1. **Efek Grafis Neon Glow Modern**:
   - Efek partikel ledakan, asap pendorong pesawat, gelombang kejut bom, dan efek getaran layar (*screen shake*).
   - Latar belakang bintang bergerak multi-lapis (*parallax starfield*).

2. **Sound FX & Musik BGM Bawaan (Web Audio API)**:
   - Suara tembakan laser, ledakan bass berdentum, suara perisai, dan alunan synthwave 80-an yang diproduksi secara dinamis tanpa butuh file audio eksternal.

3. **Musuh & Bos Epik**:
   - **Asteroid**: Batu luar angkasa yang akan terbelah menjadi 2 bagian saat ditembak!
   - **Scout Drone**: Pesawat pengintai hijau berkecepatan tinggi yang bergerak zig-zag.
   - **Assault Fighter**: Pesawat merah yang aktif menembak balik ke arahmu.
   - **Heavy Cruiser**: Pesawat ungu berpelindung tebal dengan tembakan menyebar (*spread shot*).
   - **Mothership Boss**: Muncul pada poin tertentu dengan bar darah, fase serangan berputar, dan ledakan epik!

4. **Power-Up Keren**:
   - 🛡️ **Perisai (Shield)**: Melindungimu dari tabrakan atau peluru musuh.
   - 🔱 **Triple Shot**: Menembakkan 3 berkas laser sekaligus dengan jangkauan luas.
   - ⚡ **Rapid Fire**: Kecepatan tembak laser meningkat 2x lipat.
   - 💣 **Bom EMP**: Menghabisi semua musuh biasa di layar secara instan.
   - ❤️ **Heal**: Memulihkan darah pesawat.

5. **Penyimpanan Skor Tertinggi (High Score)**:
   - Rekor skor terbaikmu akan tersimpan secara otomatis di browser (*localStorage*).
